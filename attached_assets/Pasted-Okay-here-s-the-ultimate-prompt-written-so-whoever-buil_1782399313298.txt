Codestarix — Full Design Redesign Prompt
The Brief
Codestarix is a pre-launch AI-native gamified coding education startup. The existing site has genuine soul — a deep space aesthetic, purple brand identity, gamified XP progression, and sharp copywriting. The problem is execution, not vision. This prompt is about preserving every bit of that character and making it feel like it belongs next to Linear, Vercel, and Framer — startups that made dark, minimal design feel premium rather than cheap.
The north star: Every section should feel like it was designed by a small, obsessive team that cares deeply about craft. Not a template. Not a Webflow clone. Something you'd bookmark and share.

Design System — Lock These In
Colors:

Background: #0A0A0F (near-black, not pure black — pure black looks fake)
Surface cards: #111118 with 1px solid rgba(255,255,255,0.06) border
Brand purple primary: #7C3AED
Brand purple glow: #9D6FFF (lighter, for glows and accents)
Brand purple muted: rgba(124,58,237,0.15) (for card backgrounds, tinted surfaces)
Text primary: #F0EEF8
Text secondary: #8B89A0
Text muted: #4A4860

Typography:

Display (hero, section titles): 'Clash Display' or 'Space Grotesk' from Google Fonts — geometric, confident, not generic. Weight 600–700.
Body: 'Inter' — clean, readable, trusted. Weight 400–450.
Mono/labels: 'JetBrains Mono' for XP labels, level badges, code snippets. Weight 500.
Scale: Hero H1 = 72px / Section H2 = 52px / Card title = 22px / Body = 16px / Label = 12px uppercase tracked

Motion philosophy: One ambient effect per section, nothing more. The hero stars can drift. Section reveals use a single opacity + translateY fade-in on scroll. Cards get a border-color and box-shadow shift on hover. No bounce, no spin, no particle explosion. Restraint is the flex.

GLOBAL — NON-NEGOTIABLES
[META] Add <title>Codestarix — The Coding Platform for the AI Era</title> and a proper meta description. Add Open Graph tags so link previews on LinkedIn/WhatsApp/Twitter show the logo and headline, not a blank card.
[FAVICON] Add the crystal logo as favicon. Export at 32×32 and 180×180 (for Apple touch icon).
[SCROLL REVEALS] On scroll, each section fades in with opacity: 0 → 1 and translateY: 24px → 0 over 0.5s ease. Use IntersectionObserver — no library needed. Apply to section headings and card grids independently so they stagger slightly.
[MOBILE] Two-column grids collapse to single column below 768px. Hero headline drops to 44px. Crystal illustration moves below the text or disappears on very small screens. Navbar collapses to a hamburger. The "Claim Spot" button stays visible and accessible.
[PERFORMANCE] Lazy-load images. Preload the display font. The star particle background should use canvas with requestAnimationFrame and a low particle count (150 max) — not a heavy library.

What This Should Feel Like When Done
A junior developer who finds this site at 11pm should think: "These people are serious." An investor or accelerator scout who lands on it should think: "This team has taste." A potential early user should think: "I want to be in this universe."
The space theme is not a gimmick — it's a commitment. Execute it with the same discipline that SpaceX brings to their website. Dark. Precise. Confident. No clutter. Every element earns its place
